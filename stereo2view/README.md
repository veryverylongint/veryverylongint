# Stereo2View v2 — 二视点转换器

把 SBS / TB 双目画面或 VR 视频转成 Companion-01 的 **2 视点交织图**，全屏送面板。

## 运行

```bash
open ~/Documents/Projects/companion01/stereo2view/Stereo2View.app
./Stereo2View --file a.mp4 --layout sbs --zoom 6 --testdisp 40
```

## 参数模型（v4）

源投影决定取景模型：

| 模式 | 适用 | 取景方式 |
|---|---|---|
| 直线 | 普通双目照片/游戏 | 缩放 + 平移（裁切，保纵横比） |
| 等距柱状 180 | VR180 视频 | 窗口 FOV + 偏航/俯仰，像 VR 里往外看 |
| 等距柱状 360 | VR360 视频 | 同上 |
| 鱼眼 180 | Insta360 等鱼眼素材 | 同上 |

球面模式下每个屏幕像素先算**射线方向**，再反算源图角度坐标，因此视角和缩放天然一致，不会在屏幕边缘出现固定的环。

## 参数模型（v2 重做）

真实自由度只有 4 个：

| 组 | 控制 | 说明 |
|---|---|---|
| 取景 | 缩放 / 水平 / 垂直 / 填满·适应 | 面板上拖动=平移，滚轮=缩放。**保持源像素纵横比，绝不拉伸** |
| 立体 | 交织相位 / 零视差面 px | 相位把视点分界对到两眼之间；零视差面平移右眼（不改大小） |
| 补偿 | 径向 −1…+1 | 以单眼画面中心为原点的重映射，补偿鱼眼/等距柱状 |
| 测试 | 竖条靶 + 靶视差 px | 单根竖条+十字+非对称标记，位移立刻可见；用来实测串扰容限 |

**已删除**：源瞳距、视差强度。
理由：静态双目没有深度，无法"只改视差"；任何缩放都会让两眼画面不同。视差由**取景**唯一决定。

## 命令行

| 参数 | 说明 |
|---|---|
| `--file <path>` | 图像 / 视频 |
| `--layout sbs\|tb\|mono` | 源布局 |
| `--zoom <z>` / `--shift <px>` | 缩放 / 零视差面（像素） |
| `--deviation <v>` | 交织相位（默认 3.8456375） |
| `--projcomp <v>` | 径向补偿 −1…+1 |
| `--fit fill\|letter` | 填满（裁切）/ 适应（黑边） |
| `--test` / `--testdisp <px>` | 视差靶 / 靶位移 |
| `--dump <png>` / `--autoclose <s>` | 离屏导出 / 定时退出 |

## 局限

- 2 视点：立体窗口约 5°（70 cm ≈ 6 cm），靠相位对准
- 无深度信息，不能合成中间视点
- 裁切越紧，视差与深度同步放大（等比），不能单改其一

## v4 新增

| 控制 | 作用 | 实测 |
|---|---|---|
| 进度条 | 拖动 seek，0.25 s 刷新 | ✓ |
| 窗口FOV（直线模式） | 主控：`zoom = 源FOV / 窗口FOV` | FOV 60→30，圆 470→941 px |
| 横向比例 0.5–2.0 | 长宽独立调整（配合「拉伸」模式） | ✓ |
| 视差强度 0.5–1.5 | 等价 VR 播放器的 3D depth（两眼反向缩放） | 幅度大时能看到两眼尺度差 |
| 零视差面 | 改为**对称**：左右各移一半 | 681–758 → 651–788，中心不动 |
| 边缘融合 0–30% | 越靠边越混向两眼平均，消除窗框冲突 | 边缘 R/B 255/0 → 127/127 |
| 浮窗黑边 0–60 px | 一圈黑框，画面不出屏 | ✓ |

灵敏度：滚轮 0.025（触控板）/0.10（滚轮格）；拖动 ×2。

## 窗口模式（试验）

勾选「窗口式：全入屏 + 收视角 + 窗框」后自动设置：

| 参数 | 值 |
|---|---|
| 窗口 FOV | 降到 25°（更窄=更微缩，代价是分辨率） |
| 视差强度 | 0.90 |
| 边缘融合 | 10% |
| 浮窗黑边 | 24 px |

取消勾选恢复原值。「对齐主体到屏面」用 160×120 灰度 SAD 估计整体视差，把主体视差归零（≈主体贴在屏面上）。

实测：黑边 24 px ✓；FOV 60→25 时圆 470→1129 px（理论 1128）✓；边缘融合在 x=25 处 R/B 都是 138（两眼同图），x=720 处 0/255（满视差）✓。

## 右眼对位（远景对不上先调这里）

实拍双目常见缺陷是两路没对齐（垂直偏移、微旋转、缩放差），表现为远景重影、怎么调相位都不干净。

| 控制 | 单位 | 说明 |
|---|---|---|
| 右眼垂直px | 源图像素（正值=上移） | 修垂直错位 |
| 右眼旋转° | ±2° | 修微旋转 |
| 右眼缩放% | ±5% | 修焦段/裁切差 |
| 对齐主体到屏面 | 按钮 | 自动估水平+垂直，设置零视差面与右眼垂直 |

实测：源图右眼下移 20 px 时，未对位有两条亮线（面板 1060–1128），设「右眼垂直 20 px」后合并为一条（1060–1076）。

## 为什么远景"对不上"

面板在 70 cm 观看时的深度预算只有 **±6 cm**（视差 ≈7% 屏宽）。真实场景里的远景（2 m、5 m）需要的视差远超这个值——一个 5 m 远的物体要 4.4° 视差，等于 76% 屏宽，根本不可能融合。所以远景不是"映射缺要素"，而是**物理上放不进这块屏**：必须在 6 cm 的厚度里压扁整个场景。
