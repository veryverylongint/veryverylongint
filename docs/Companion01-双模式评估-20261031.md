## 2. 当前实现（关键链路）

```
相机：固定朝向 + 水平平移 + 离轴投影（无 toe-in、无垂直视差）
旋转：trackball 四元数，绕模型中心，无极点
cells   = max(1, N·ipdDeg/Z)            ipdDeg = 2·atan(IPD/2D)
effVol  = clamp(0.8873·(volCM/2)/(Dcm+volCM/2), 预算)
step    = 2·effVol/cells × perspComp     perspComp = clamp(f/45, 1.2, 2.2)
上限     = min(0.026·立体强度, 0.28/(N−1))   ← 双上限：单步 / 扇面
shift   = −off/halfW_zero                halfW_zero = (d + focusSlice·rBound)·Tan
interleave：逐子像素取视点，亮度保留定向、色度 70% 向中心视点收敛
```

当前默认：N=20、Z=40°、D=0.7 m、IPD=63、f=85 mm、volCM=2.2、popCM=1.5、立体强度 1.8。

## 5. 物理约束推导（决定设计空间）

三个量互相锁死：

```
每步 s = 扇面 S / (N − 1)
子像素/视点 = 19.6349 / N
双目总视差 = cells × s = S · cells/(N−1)
```

| 目标 | 需要 | 代价 |
|---|---|---|
| 出屏强（大视差） | 大 S | 外视点被推出画面；单眼看到双轮廓 |
| 移动平滑 | 大 N（每步小） | 每视点子像素少 → 彩边/发糊 |
| 单眼无重影 | 小 s（≤1 个透镜周期 ≈ 6.5 px） | 深度被压平 |
| 每个视点干净（无彩边） | N ≤ 6.5 | 方向只有 4–6 个 → 移动跳格 |

**核心结论：出屏强度、移动平滑、单眼干净，三者最多取两个。**

当前版本取的是「平滑 + 单眼干净」，牺牲出屏 → 观感"稳定但不强"。
A 版取的是「出屏 + 体积」，牺牲单眼干净 → "强但晕、被裁"。

## 6. 用户提出的双模式设想

> "出屏（内外整体）深度和准确体积能不能兼容，还是需要分开显示模式？
> 明显跳变的模式（突出深度但低视点数仍清晰），
> 和类似现在移动变化很稳定（出屏清晰度有限制）的模式？"

**这与物理约束完全吻合**，两种模式的参数可以这样设计：

### 模式 A：跳变突出（Pop Mode）

| 参数 | 值 | 理由 |
|---|---|---|
| N | **4**（或 6） | 每视点 4.9 子像素 → 整像素 RGB，无彩边 |
| 扇面 S | 允许 0.6–1.0 NDC | 大视差 = 强出屏 |
| 每步 s | 0.2–0.33 NDC（150–240 px） | 视点少，本身就是"跳变" |
| cells | 0.5（Z=40, 0.7 m）→ 夹 1 | 甜甜圈窄：眼睛跨过分界线时才有立体，但一跨就很强 |
| 观感 | 强出屏、干净、移动跳格 | 符合用户"明显跳变但清晰" |

### 模式 B：稳定移动（Smooth Mode）

| 参数 | 值 | 理由 |
|---|---|---|
| N | **20** | 每步小 → 移动连续 |
| 扇面 S | 0.25–0.30 NDC | 内容不出画 |
| 每步 s | 0.013–0.015 NDC（9–11 px） | 单眼不分离 |
| cells | 2.58（Z=40） | 甜点区宽，站立不动也稳定 |
| 观感 | 深度弱但稳、可长时间看 | 当前版本即此模式 |

**中间路线**：N=8~10 + 扇面 0.4，得到「移动较平滑 + 出屏中等 + 每视点 2.4 子像素（轻微彩边）」。

## 7. 已有实现里待修正的地方

1. **双上限可能过度保守**：`0.28/(N−1)` 是拍出来的，不是光学推导；它对 N=4 的模式 A 完全不适用（会限到 0.093）。
2. **volCM 与 popCM 的语义**：volCM 走的是"体积视差"，popCM 走的是"共同模"，两者都吃同一份 `step` 预算，用户感觉"volCM 拉不出出屏"是对的——出屏由 popCM 单独控制，但被上限截断。
3. **突出位置发糊**：视点密度不足，只能靠降 volCM / 降 N 缓解。
4. **Z 的真值未定**：90°（跳视全周期）与 40°（近轴区）差 2.25 倍，直接影响 cells 与甜点区宽度。

## 8. 给外部模型的问题

1. **双上限是否合理**？还是应该直接以「扇面 S」为唯一主控，让每步 s = S/(N−1) 自然得出？
2. **模式 A 的 N=4 是否真的无彩边**？N=4 时每视点 4.91 子像素，但透镜 PSF 会混入相邻 2–3 个子像素——是否仍会在高对比边缘产生色边？
3. **能否用"深度压缩 + 出屏分离"两套参数**：即模型体积用一套视差（准），出屏整体用另一套（强），二者叠加是否违反光场一致性？
4. **N 对深度观感的贡献**：用户明确说"视点数增加让深度更真实"。在静态双目视差固定的前提下，这种提升是否完全来自运动视差（kinetic depth）？如果是，模式 B 的"深度弱"是否可以靠更密的视点弥补，而不必增大扇面？
5. **1 cm 出屏是否是硬天花板**？按 19.63 子像素 / 20 视点推导，双目总视差被扇面限制在 0.28 NDC ≈ 0.6% ≈ 4–6 mm 出屏。有没有可能通过降低 N（模式 A）突破到 3–5 cm？
6. **混合方案**：上半屏用模式 A（强出屏）、下半屏用模式 B（稳定），让用户对比后再二选一——是否值得做？
